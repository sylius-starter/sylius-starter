# sylius-starter/core

Core of Sylius Starter: the Castor plugin. It provides the `SyliusService` Docker service, the `castor docker:service:install sylius` installer, the `sylius:fixtures` task and the extension points (task providers, installer/remover contracts, installer extensions) used by the other packages.

## Installation

In your Castor project:

```bash
castor composer require sylius-starter/core
```

Or install every Sylius Starter package at once with `sylius-starter/sylius-starter`.

Read the [documentation](https://github.com/sylius-starter/sylius-starter#readme) for usage.
