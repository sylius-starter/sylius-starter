# sylius-starter/themes

Ready-to-use Sylius storefront themes (Canvas, Blush, Prompt Dark, Prompt Light, Volt): `sylius:theme:setup`. Custom themes can be declared with the `#[AsThemeInstaller]` and `#[AsThemeRemover]` attributes.

## Installation

In your Castor project:

```bash
castor composer require sylius-starter/themes
```

Or install every Sylius Starter package at once with `sylius-starter/sylius-starter`.

Read the [documentation](https://github.com/sylius-starter/sylius-starter#readme) for usage.
